Short complete conversation contexts defer unnecessary summaries to reduce generation latency while retaining safety metadata. Three synthetic comparisons were 1.01–1.29s compact vs 3.41–8.32s baseline; this small provider sample is not a device latency guarantee.

V12 removes the separate session-analytics toggle. The short Profile privacy paragraph uses generic external-AI wording; the public full policy accurately identifies processing providers and company ownership.

## Notifications and administration

FCM notifications are optional and ask once on first authenticated home launch; an already-enabled installation is not prompted again. SDK auto-init defaults disabled; token refresh, account changes, logout, opt-out and account deletion manage registrations. Native foreground notifications and the FCM background payload use a private lockscreen channel. The owner confirmed dashboard notification receipt on a real phone.

The protected RTL admin composer supports preview plus explicit confirmation for all opted-in devices or one account. Atomic campaign claims prevent repeat sends. Unknown outcomes are not retried; Google acceptance does not prove delivery/read. The agent did not send real test notifications.

Hourly UTC Cloudflare Cron schedules generic reminders using only coarse chat-use hours and timezone. The preferred evening hour is 18:00–23:00 local, default 20:00. Recent activity within two hours and inactivity over thirty days suppress reminders. Atomic per-account rolling-24-hour claims prevent duplicates, including uncertain sends; current device/account status is checked again before send. Admin-confirmed campaigns can be sent at any time independently. Settings retain opt-out for both kinds.

The admin dashboard includes account/email management, settings, audit, operational latency/token metrics, 7/30/90/custom ranges, aggregate topic/mood ranks with unique accounts, before/after matrix, and CSV export. The positive end-rating denominator excludes unfinished/skipped ratings and is not a clinical measurement. A 10,000-session cap is disclosed; metrics represent recorded sessions, not every install.
